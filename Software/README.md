# 焊点人工标注软件

当前已完成阶段 8：数据导入、图片浏览、人工红圈、Weld Name 绑定与批量出图。

已支持：

- 选择原始图片文件夹（PNG/JPG/JPEG/BMP/TIF）
- 选择手持设备 CSV/XLSX/XLSM 清单
- 选择工作表与 `Weld Name` 列
- 自动按数据行顺序生成序号
- 校验图片数量、空 Weld Name 与重复 Weld Name
- 将项目索引保存到 `Software/projects`，不修改原始图片或清单
- 可在既有项目中补充图片：同一路径自动跳过；同名但不同路径列为冲突且不导入

已支持：

- 图片按自然数字顺序显示，例如 `1.png、2.png、…、10.png、11.png`
- 原图浏览、缩放、空格拖动画布、适应画布
- 单击新增红圈、拖动移动、调整半径、删除
- 红圈与手持清单 Weld Name 一对一绑定、解除绑定与重复拦截
- 红圈几何位置与绑定状态自动保存到项目 SQLite

已支持：

- 会话内撤销/恢复红圈新增、移动、尺寸修改、绑定、解除绑定与删除
- 跳到下一未绑定红圈、下一未分配 Weld Name
- 导出每个已确认绑定为独立 PNG，命名为 `序号_Weld Name.png`
- 每张导出图仅绘制该编号对应的一个红圈，统一使用红色
- 导出 `出图清单.xlsx`、`出图清单.csv`、未绑定红圈、未分配 Weld Name 与问题清单

尚未支持：OCR、跨项目汇总。

## 启动

在工作区根目录执行：

```powershell
conda run -n pyside python .\Software\src\app.py
```

运行环境复用现有 Conda `pyside` 环境，不需要下载新的软件包。

## 导入项目

1. 启动程序后，在“项目工作台”点击“新建项目”。
2. 选择原始图片文件夹与手持设备清单。
3. CSV 选择 `CSV` 工作表；Excel 选择对应工作表。
4. 确认 `Weld Name` 列后查看预检查结果。
5. 点击“创建项目索引”。

项目元数据保存在 `Software/projects/时间戳_项目名/`。源图片和源清单保持不变。

## 补充图片

打开既有项目后，点击左侧“补充图片”，选择包含新增图片的文件夹。程序会先显示扫描结果；确认后只索引可新增图片，已有红圈、绑定和源文件均不会变更。同一路径图片会跳过；不同路径但同名的图片为冲突项，不会自动导入。

## 人工标注与编号绑定

1. 在左侧按数字顺序选择图片。
2. 单击原图空白处新增红圈，或选中、拖动已有红圈。
3. 在右侧搜索并选择一个未分配 Weld Name。
4. 点击“绑定到选中红圈”。绑定成功后红圈变为绿色，并显示手持序号。
5. 若需修改，选中绿色红圈后点击“解除当前红圈绑定”，再选择新编号。

同一个 Weld Name 只能绑定一个红圈；源图片和手持清单不会被改动。

## 导出已确认图片

1. 点击标注工作台右上角的“导出已确认”。
2. 程序先检查原图、红圈边界、绑定关系和输出文件名。
3. 没有阻断问题时，导出所有已确认绑定；未绑定红圈和未分配 Weld Name 会写入清单，但不阻止已确认项出图。
4. 若存在阻断问题，只生成问题清单，不生成 PNG。

每次导出建立独立批次：

```text
Software/projects/项目目录/exports/时间戳_序号/
  images/
  出图清单.xlsx
  出图清单.csv
```

详细设计与环境说明见 [开发手册.md](开发手册.md)。
