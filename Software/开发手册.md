# 焊点人工标注软件开发手册

> 状态：阶段 8 出图与验收已完成。本文档建立于 2026-11-09；已接入项目、图片目录、手持清单、原图浏览、人工红圈、Weld Name 一对一绑定、会话内撤销/恢复与独立图片出图，**尚未接入 OCR 或打包发布**。

## 1. 软件目标

建立一套 Windows 本地运行的人工标注工具，用于把原始车型截图中的焊点位置，与手持设备清单中的 `序号 + Weld Name` 绑定，并批量导出带红圈的图片。

最终文件名规则：

```text
序号_Weld Name.png
010_61205-01-R.png
011_61205-07-R.png
```

核心原则：

- 手持设备清单是最终编号依据；OCR 仅作为候选，不直接决定编号。
- 原始截图永不修改；红圈图全部输出到新目录。
- 每个点击位置、红圈大小、人工修改和导出批次均可追溯。
- 未匹配、重复编号、未确认的标注不能混入正式出图。

## 3. 技术选型

### 3.1 结论：PySide6 桌面程序

采用 Python + PySide6 的 Windows 桌面程序。

原因：

- 图片均在本地磁盘，直接选择文件夹和批量读写更自然。
- 焊点标注依赖大图缩放、平移、鼠标点位、拖动红圈、快捷键与撤销；Qt 的 `QGraphicsView/QGraphicsScene` 对这些场景适配较好。
- 不需要启动浏览器或维护本地 Web 服务。
- 后续使用 PyInstaller 打包后，可双击运行。

浏览器方案保留为未来扩展：如果需要多人同时标注、远程审核或跨电脑访问，再采用 React + FastAPI。当前不采用 Streamlit 作为正式工具；它适合快速展示数据，但复杂图元编辑、撤销和快捷键体验较弱。

### 3.2 依赖清单

| 包 | 首版用途 | 是否必须 |
|---|---|---:|
| `PySide6-Essentials` | 窗口、表格、文件选择、`QGraphicsView` 图片标注画布 | 是 |
| Pillow | 原图读取、按标注坐标绘制红圈、PNG 导出 | 是 |
| openpyxl | 导入/导出 Excel 清单和复核表 | 是 |
| Python 标准库 `sqlite3` | 保存项目、标注、审计记录 | 是，无需下载 |
| RapidOCR | 以后生成 OCR 候选 | 否，沿用现有独立 OCR 环境 |

首版选择 `PySide6-Essentials`，不安装完整的 `PySide6` 元包。前者已足够提供 Widgets 与 Graphics View；完整元包还会带入 Addons，目前没有必要。

### 4.3 备用方案：新建独立环境时需要下载

是，需要下载。当前 pip 缓存没有这些安装包。

以 Windows x64、Python 3.11 为目标，预估如下：

| 内容 | 预计下载量 | 说明 |
|---|---:|---|
| PySide6-Essentials | 约 80–85 MB | Qt Widgets 等核心运行库 |
| shiboken6 及安装元数据 | 数 MB | PySide6 依赖 |
| Pillow | 约 3–10 MB | 与版本、Python 标签有关 |

## 6. 数据设计

### 6.1 项目文件

每个车型或部件建立一个独立项目。项目保存：

- 原图文件夹路径
- 手持设备清单路径与列映射
- OCR 候选结果路径（可选）
- 输出目录
- 标注数据库路径

### 6.2 SQLite 数据表

| 表 | 关键字段 | 用途 |
|---|---|---|
| `images` | `id, path, width, height, hash` | 原始图片索引与变更检查 |
| `welds` | `id, handheld_serial, weld_name, status` | 手持清单中的待标注焊点 |
| `annotations` | `id, image_id, weld_id, center_x, center_y, radius_x, radius_y, source, status` | 红圈位置与确认状态 |
| `events` | `id, annotation_id, action, before, after, created_at` | 新增、移动、删除、确认的审计记录 |
| `exports` | `id, path, created_at, record_count` | 每次出图批次记录 |

坐标必须保存为**原图像素坐标**。界面缩放只是显示转换，不能改写存储坐标。

## 7. 首版界面设计

### 7.1 首页：项目管理

- 新建项目
- 打开已有项目
- 选择原始图片目录
- 导入手持清单 CSV/XLSX
- 可选导入既有 OCR 结果 CSV
- 显示图片数、清单数、已确认数、待复核数

### 7.2 标注工作台

```text
┌───────────────┬─────────────────────────────────────┬─────────────────────┐
│ 图片列表       │ 原图画布：缩放、拖动、红圈编辑        │ Weld Name 清单       │
│ 1.png          │                                     │ 搜索框               │
│ 2.png          │              ⭕ 焊点                 │ 未标注 / 已标注      │
│ ...            │                                     │ OCR 候选             │
├───────────────┴─────────────────────────────────────┴─────────────────────┤
│ 当前状态｜上/下一张｜撤销｜确认标注｜导出预览                              │
└──────────────────────────────────────────────────────────────────────────┘
```

交互规则：

1. 选择一张原图。
2. 点击画布生成一个可调整的红圈。
3. 在右侧搜索并绑定未使用的 `Weld Name`。
4. 自动带入手持序号，例如 `011`。
5. 确认后变为绿色；OCR 候选但未确认显示黄色；冲突项显示红色。

### 7.3 必备快捷操作

- 滚轮：缩放
- 空格拖动：平移画布
- 单击空白处：新增红圈
- 单击红圈：选择；拖动：移动
- `Delete`：删除当前红圈
- `Ctrl + Z`：撤销
- `Enter`：确认当前标注
- `N`：下一张图片

## 8. 导入、校验与出图规则

### 8.1 导入

- 手持清单必须指定 `Weld Name` 列；序号可读取现有列，或按数据行顺序自动生成。
- 同一项目内默认一个 `Weld Name` 只能绑定一个红圈。
- 导入现有 OCR CSV 时，`ocr_code` 用作候选名称，`ocr_serial` 只保留追溯，不作为最终序号。

### 8.2 出图前阻断项

- 同一 Weld Name 重复绑定
- Weld Name 不在手持清单内
- 红圈超出原图边界
- 未确认的候选标注

### 8.3 导出内容

每次导出创建新批次，不覆盖历史结果：

```text
exports/2026-11-09_001/
  images/
    010_61205-01-R.png
    011_61205-07-R.png
  出图清单.xlsx
  出图清单.csv
  未标注清单.xlsx
  待复核清单.xlsx
```
